======================================================================
3. SCORING MECHANICS (same for both roles)
======================================================================

Each criterion scored 0–4 on EVIDENCE only (a named artefact, a metric, an
adoption count, a quote from a reviewer). Adjectives score 0.
  4 = repeated, quantified, owned end-to-end
  3 = one clear quantified instance, owned
  2 = present but supporting role, or unquantified
  1 = adjacent / weak signal
  0 = absent
Weighted score = sum( weight x score / 4 )   -> 0–100

ROUTING (automatable):
  ADVANCE        score >= 75 AND gate G1 passes
  HUMAN REVIEW   score 55–74, OR score >= 75 with G1 failing,
                 OR any rescue rule fires
  REJECT         score < 55 and no rescue rule fires

GATE G1 — product/system ownership evidence: has owned a product, module,
platform or integration decision end-to-end (PM, eng lead owning a module,
platform owner). G1 never rejects — failing it only blocks AUTO-advance.

RESCUE RULES (stop good profiles being rejected):
  R1  Score 4 on BOTH pattern criteria (P1 + P2)       -> human review
  R2  PM-title tenure at or above JD floor (PM 2+ yrs,
      SPM 5+ yrs)                                       -> human review
  R3  Lived ground-level logistics tenure >= 2 yrs      -> human review
  R4  Parser confidence low / CV non-standard format    -> human review

NEVER-SCORE LIST: years of PM title (used only in R2), school tier, MBA,
certifications, company brand, conference talks, tool lists.

FLAGS (attach to record, do not change score):
  F1  SPM candidate with < 4 yrs in ownership roles -> "probe seniority"
  F2  Relocation to Mumbai not stated -> "confirm in-office"

======================================================================
7. AUTOMATION FLOW
======================================================================

 1. Ingest CV (.docx/.pdf) -> plain text
 2. LLM extraction: for each criterion, return quoted evidence lines from
    the CV + score 0–4 + one-line reason. No quote = score 0.
 3. Compute weighted score in code (not by the LLM)
 4. Evaluate G1, R1–R4, F1–F2 in code
 5. Route: ADVANCE / HUMAN REVIEW / REJECT; write row to tracker
 6. Weekly: recruiter samples 10% of REJECTs; if any would have advanced,
    lower the reject line by 5 and log it
 7. Quarterly: join scores to real performance ratings; re-fit weights

Human time goes only to the review band. Audit trail = quoted evidence.
